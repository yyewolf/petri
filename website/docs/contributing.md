# Contributing

petri is developed on [GitHub](https://github.com/yyewolf/petri). The
contributor documentation lives in the repository:

- [CONTRIBUTING.md](https://github.com/yyewolf/petri/blob/main/CONTRIBUTING.md):
  tooling, the mirrored upstream code, and pull requests;
- [docs/design.md](https://github.com/yyewolf/petri/blob/main/docs/design.md):
  the decisions petri is built on, and why;
- [docs/releasing.md](https://github.com/yyewolf/petri/blob/main/docs/releasing.md):
  versions, branches and how releases are made.

This site is built from `website/` in the same repository. Its code samples are
tests in `website/examples`, which CI runs; to change a sample, change the test.
