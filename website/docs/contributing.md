# Contributing

petri is developed on [GitHub](https://github.com/yyewolf/petri). The
contributor documentation is in the repository:

- [CONTRIBUTING.md](https://github.com/yyewolf/petri/blob/main/CONTRIBUTING.md)
  covers tooling, the mirrored upstream code and pull requests.
- [docs/design.md](https://github.com/yyewolf/petri/blob/main/docs/design.md)
  records the decisions petri is built on, and why.
- [docs/releasing.md](https://github.com/yyewolf/petri/blob/main/docs/releasing.md)
  explains versions, branches and releases.

This site is built from `website/` in the same repository. Every code sample
is a test in `website/examples` that CI runs, so to change a sample, change
its test.
