# API reference

The Go documentation for every exported identifier is on pkg.go.dev:

- [`github.com/yyewolf/petri`](https://pkg.go.dev/github.com/yyewolf/petri):
  control planes, namespaces, waits, CRDs, webhooks, controllers, Nodes and
  Pod expectations.
- [`github.com/yyewolf/petri/controllerruntime`](https://pkg.go.dev/github.com/yyewolf/petri/controllerruntime):
  the controller-runtime Manager helper and waits for controller-runtime
  clients.
- [`github.com/yyewolf/petri/controllerruntime/envtest`](https://pkg.go.dev/github.com/yyewolf/petri/controllerruntime/envtest):
  the envtest drop-in.

To read the documentation for the release you depend on, pick it in
pkg.go.dev's version selector.
